# Contributing

1. Fork `niv-command-center-public` and create a branch for your change.
2. Install with `npm ci` and follow [TESTING.md](TESTING.md).
3. Keep changes focused; update setup docs when behavior changes.
4. Run the production build, unit/database tests, browser tests and PWA tests.
5. Open a pull request describing the change and the checks you ran.

Do not submit credentials, tokens, personal records, account identifiers or screenshots of live accounts. Use fictional fixtures and mocked services. Preserve RLS, read-only Graph permissions, completed-task filtering and third-party licenses.
